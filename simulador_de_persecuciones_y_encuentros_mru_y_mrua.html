📐 Formulario Base del Simulador (MRU y MRUA)

1. Movimiento Rectilíneo Uniforme (MRU)

Velocidad constante (v = cte), aceleración nula (a = 0), vᵢ = vᶠ:

xᶠ = xᵢ + v · t
2. Movimiento Rectilíneo Uniformemente Acelerado (MRUA)

Aceleración constante (a = cte):

1) vᶠ = vᵢ + a · t
2) xᶠ = xᵢ + vᵢ · t + ½ · a · t²
3) xᶠ = xᵢ + ½ · (vᶠ + vᵢ) · t
4) vᶠ² = vᵢ² + 2 · a · (xᶠ - xᵢ)
3. Condición Analítica de Persecución y Encuentro

Dos vehículos se encuentran en el instante t > 0 cuando sus posiciones coinciden: xᶠ,A(t) = xᶠ,B(t). Esto genera una ecuación lineal (MRU vs MRU) o cuadrática A·t² + B·t + C = 0 cuyas raíces reales positivas determinan los tiempos exactos de alcance o cruce.
